# 목업 v2 브리프: 기업형 디자인 방향 5종 (2026-10-07)

v1(같은 스타일, 화면 5개)이 "유아틱하다"는 피드백을 받았다. v2는 **같은 화면(홈 · 오늘의 화물 보드)을 서로 다른 기업형 방향 5가지로** 그려 고를 수 있게 한다.

## v1이 유아틱해 보인 이유 (v2에서 금지)

- 판정 배지·칩에 파스텔 바탕을 깔고 앞에 색 사각 점을 붙였다
- KPI 숫자를 판정색으로 크게 칠했다 (빨강 2, 주황 3, 초록 4)
- "지금 할 일" 노란 상자, 파란 "지금 할 일" 라벨 같은 장식
- 말투가 친근하다 ("먼저 보여 드려요", "1분이면 끝나요")
- 화살표·눈 아이콘 같은 귀여운 기호, 동그란 아바타 이니셜
- 카드마다 3px 색 윗띠
- 여백이 크고 정보 밀도가 낮다

## v2 공통 규칙

- 색: 기본은 무채색(흰·회·남색/먹색) + 강조색 1개. 판정색은 **작은 글자·얇은 선·작은 점 하나**로만 쓰고 바탕을 칠하지 않는다. 숫자는 먹색.
- 말투: 짧은 명사형 라벨과 담백한 서술("판매 예정일 2일 초과", "입항 지연 예상"). 버튼은 동사 2~4자("조회", "확인", "내보내기").
- 밀도: 표 행 높이 36~40px, 본문 13~14px, 라벨 11~12px. 화면 하나에 정보가 꽉 차 보이게.
- 모서리 0~4px. 그림자 없음(떠 있는 메뉴만 예외). 아이콘은 단색 선 아이콘(인라인 SVG, 1.5px)만.
- 글꼴: "Pretendard", "Noto Sans KR", "Malgun Gothic", -apple-system, sans-serif. 숫자는 tabular-nums. 외부 로드 금지.
- 단일 HTML, 인라인 CSS, JS 없음, 25KB 이하, 1440px 기준(1024px까지 가로 넘침 없음).
- 데이터는 모두 가공값(B/L은 MRVD****0001 식, 배 이름 DEMO/TEST, 포워더 데모포워딩).
- 실제 회사 로고·상표·이름은 쓰지 않는다. 스타일만 참고한다.

## 화면 내용 (5개 모두 같은 데이터)

- 셸: 로고 "Marvia", 메뉴 홈/물어보기/내 화물/알림·설정/관리(운영자), 사용자 영역(이름 텍스트 "김승욱 · 운영자" 또는 이니셜, 원형 금지)
- 머리: 화면 제목 "오늘의 화물", 기준 시각 "2026-10-07 (수) 14:30 기준", 오른쪽 버튼 [전체 다시 조회] [내보내기]
- KPI 4칸: 지켜보는 화물 9 / 긴급 2 / 주의 3 / 순항 4 (전일 대비 증감 작게: 긴급 +1)
- 변동 내역 표(3줄): 시각, 화물, 이전 판정 → 현재 판정, 사유, [확인]
- 조치 필요 화물 표(5줄): 판정, 화물(품명)·B/L, 선박, 도착 예정, 판매 예정일, 여유(일), 통관 단계, 조치 사항, 담당 포워더
- 보조 칸: 빠른 조회(B/L, 판매 예정일, 조회 버튼), 알림 연결 상태(카카오 미연결), 데이터 출처 상태(AIS · 해수부 · UNI-PASS 마지막 수신 시각)
